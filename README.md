# Mandarin Games · Administration Minecraft

Статический демо-портал администрации Minecraft проекта Mandarin Games. Вкладка C.A.S.S.I.E. содержит пример оповещения с копированием полного текста.

## Публикация

Распакуйте `mandarin-games-mrp.zip` и загрузите файлы из архива в корневую папку статического хостинга. Серверная сборка не нужна.

Для локального просмотра откройте `index.html` в браузере.

## Важно

Кнопки Google и Steam показывают только демо-макет входа и не проверяют аккаунты. Для реальной авторизации нужны Google OAuth, Steam OpenID и серверная проверка доступа. Не размещайте реальные персональные данные в этой демо-версии.
