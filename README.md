# Mandarin Games · MRP

Статическая демо-страница для отдела MRP сообщества SCP: Secret Laboratory.

## Публикация

Распакуйте `mandarin-games-mrp.zip` и загрузите `index.html` вместе с `1456258267201278195.webp` в корневую папку статического хостинга. Файлы должны остаться рядом. Серверная сборка не нужна.

Для локального просмотра откройте `index.html` в браузере.

## Важно

Вход Google и Steam, заявка и её одобрение реализованы только как локальная демонстрация в текущем браузере. Для реальной OAuth-авторизации, хранения заявок и защищённого доступа к внутренним данным необходим сервер с проверкой токенов и ролей. Не размещайте реальные персональные данные в этой демо-версии.
